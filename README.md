# Lampa Remote Config v1.1

Плагин для удалённой настройки Lampa между **ПК** и **ТВ** по 6-значному коду.

### Что умеет

- Смотреть список плагинов на ТВ
- Добавлять плагин по URL
- Включать / выключать / удалять плагины
- Перезагружать Lampa на ТВ

### Сети

| Сеть                        | Как работает                          |
|----------------------------|---------------------------------------|
| **Любая** (разные сети)    | Через PeerJS Cloud (интернет)         |
| **Домашняя Wi-Fi** (одна сеть) | Прямое P2P-соединение, очень быстро |

В одной домашней Wi-Fi сети соединение устанавливается напрямую между устройствами — это самый стабильный и быстрый вариант.

## Установка

1. Создай репозиторий на GitHub и залей файлы.
2. Включи **GitHub Pages** (Settings → Pages → Deploy from branch `main`).
3. В Lampa (на **ПК** и на **ТВ**):

```
Настройки → Расширения → Добавить плагин
```

Ссылка:

```
https://ТВОЙ_ЮЗЕР.github.io/lampa-remote/remote-config.js
```

Можно также использовать raw-ссылку:

```
https://raw.githubusercontent.com/ТВОЙ_ЮЗЕР/lampa-remote/main/remote-config.js
```

---

## Как пользоваться

### На ТВ (хост)

1. Открой **Настройки → Remote Config**
2. Нажми **«Стать хостом (ТВ)»**
3. Появится большой **6-значный код**

### На ПК (контроллер)

1. Открой **Настройки → Remote Config**
2. В поле **«Подключиться по коду»** введи код с ТВ
3. После успешного соединения откроется экран управления плагинами ТВ

---

## Советы

- Лучше всего работает, когда оба устройства в **одной домашней Wi-Fi** сети.
- Код действует, пока на ТВ активен режим хоста.
- Если код «занят» — плагин автоматически сгенерирует новый.
- После добавления/удаления плагинов рекомендуется нажать **«Перезагрузить ТВ»**.

---

## Технологии

- PeerJS (WebRTC DataChannel)
- Публичные STUN-серверы (Google + Cloudflare)
- Полностью клиентский, без своего сервера
